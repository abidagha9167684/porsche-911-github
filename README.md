# 911 – interactive 3D website concept

An interactive 3D Porsche 911 showcase that runs entirely in the browser.

**Live demo:** https://abidagha9167684.github.io/porsche-911-github/

## What it does
- The car drifts into the page in real-time 3D (Three.js / WebGL)
- Start engine, race and drift, with engine sound and exhaust smoke generated in code (Web Audio API, particle system)
- Drag to look around the car in 360°
- Scroll-driven section where the headlights switch on
- Flip-book magazine, exploded view of the car, paint mixer, heritage timeline and more
- Responsive layout for phones and tablets

## Tech
Three.js, WebGL, Web Audio API, HTML, CSS, JavaScript (no build step).

## Run locally
Serve the folder with any static web server, for example `python -m http.server 8000`, and open http://localhost:8000.
